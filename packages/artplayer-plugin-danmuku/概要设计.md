# artplayer-plugin-danmuku 概要设计（详细版）

## 项目概述

**项目名称**: artplayer-plugin-danmuku  
**版本**: 5.3.0  
**开发者**: Harvey Zhao  
**许可证**: MIT

这是一个为 ArtPlayer HTML5 视频播放器开发的弹幕插件，支持实时弹幕显示、弹幕合并、共识弹幕（英雄弹幕）调度等高级功能。

### 技术栈

- **开发语言**: JavaScript (ES2020+)
- **构建工具**: Vite
- **样式处理**: LESS
- **性能优化**: Web Worker + WebAssembly (WASM)
- **模块格式**: UMD + ESM (双格式输出)

## 模块 1: index.js（插件入口）

**文件路径**: `src/index.js`  
**代码行数**: 39 行  
**职责**: 插件的入口点，导出公共 API

### 流程

```
1. 导入三个核心模块
   ├── Danmuku (核心弹幕类)
   ├── heatmap (热力图)
   └── Setting (设置面板)

2. 导出 artplayerPluginDanmuku 函数
   ├── 接收 option 参数（用户配置）
   └── 返回一个函数，接收 art 实例

3. 在 art 实例中初始化
   ├── 创建 Danmuku 实例
   ├── 创建 Setting 实例
   └── 如果开启 heatmap，初始化热力图

4. 返回公共 API 对象
   ├── emit: 发送弹幕
   ├── load: 加载弹幕
   ├── config: 动态配置
   ├── hide/show: 隐藏/显示弹幕
   ├── reset: 重置弹幕
   ├── mount: 挂载发射器
   ├── option: 当前配置
   ├── queue: 弹幕队列
   ├── isHide: 是否隐藏
   └── isStop: 是否停止
```

### 关键代码

```javascript
export default function artplayerPluginDanmuku(option) {
  return (art) => {
    const danmuku = new Danmuku(art, option)
    const setting = new Setting(art, danmuku)

    if (danmuku.option.heatmap) {
      heatmap(art, danmuku, danmuku.option.heatmap)
    }

    return {
      name: 'artplayerPluginDanmuku',
      emit: danmuku.emit.bind(danmuku),
      load: danmuku.load.bind(danmuku),
      // ... 其他方法
    }
  }
}
```

### 流程 2: load() 方法（加载弹幕）

```
async load(danmuku)
│
├── 1. 获取弹幕数据（支持多种格式）
│   ├── typeof target === 'function'  → await target()
│   ├── target instanceof Promise     → await target
│   ├── typeof target === 'string'    → bilibiliDanmuParseFromUrl(target)
│   └── Array.isArray(target)         → target (直接使用)
│
├── 2. 预处理 + 合并（交给 Worker，WASM 在 Worker 内运行）
│   ├── 计算并行 Worker 数量
│   │   ├── danmus.length < 5000 → 1 个 Worker
│   │   └── danmus.length >= 5000 → min(hardwareConcurrency - 1, 8) 个 Worker
│   │
│   ├── 如果 workerCount <= 1 或未开启合并
│   │   └── 单 Worker 路径：postMessage({ type: 'mergeDanmuku' })
│   │
│   └── 如果 workerCount > 1 且开启合并
│       └── parallelMerge() 多 Worker 并行路径
│           ├── 按时间区间将弹幕分成 N 个分片
│           ├── 并行创建 N 个 MergeWorker
│           ├── 并行初始化 WASM（每个 Worker 独立加载）
│           ├── 并行处理各分片（预处理 + WASM 合并）
│           ├── 合并所有结果、按时间排序
│           └── 终止所有 Worker
│
├── 3. 英雄弹幕调度
│   └── scheduleHeroDanmuku(danmus)
│       ├── 按 30 秒分桶
│       ├── 每桶选 ∑ > 10 的弹幕作为候选
│       ├── 前 5 名中随机选 1 个作为英雄
│       ├── 标记 _isHero = true, mode = 1
│       └── 同桶其余 ∑ > 5 的弹幕强制降级为 mode = 0
│
├── 4. 清空旧数据（如果是重新加载）
│   ├── this.reset()
│   ├── this.queue = []
│   ├── this.states = { wait: [], ready: [], emit: [], stop: [] }
│   ├── this.$refs = []
│   └── this.$danmuku.textContent = ''
│
├── 5. 逐条验证并加入队列
│   └── for (let i = 0; i < danmus.length; i++) {
│         await this.emit(danmus[i])
│       }
│
└── 6. 触发加载完成事件
    └── art.emit('artplayerPluginDanmuku:loaded', this.queue)
```

### 流程 3: emit() 方法（转换弹幕到队列）

```
async emit(danmu)
│
├── 1. 校验弹幕数据
│   └── this.validator(danmu, {
│         id: '?string',
│         text: 'string',
│         mode: '?number',
│         color: '?string',
│         time: '?number',
│         border: '?boolean',
│         style: '?object'
│       })
│
├── 2. 设置默认值
│   ├── 文本为空 → 忽略
│   ├── time 不存在 → 默认 currentTime + 0.5
│   ├── mode 不存在 → 默认 option.mode
│   ├── color 不存在 → 默认 option.color
│   ├── style 不存在 → 默认 {}
│   └── mode 不是 0 或 1 → 忽略
│
├── 3. 自定义过滤
│   └── if (!this.option.filter(danmu)) return this
│
├── 4. 创建弹幕对象
│   └── const item = {
│         ...danmu,
│         $state: 'wait',        // 初始状态
│         $index: this.index++,  // 唯一索引
│         $ref: null,            // DOM 节点
│         $restTime: 0,          // 剩余时间
│         $lastStartTime: 0      // 上次开始时间
│       }
│
├── 5. 加入状态池
│   ├── this.states.wait.push(item)
│   └── this.queue.push(item)
│
└── 6. 弹幕状态说明
    ├── wait: 等待显示，未加入 DOM
    ├── ready: 准备好显示，未加入 DOM
    ├── emit: 正在显示，已加入 DOM
    └── stop: 停止显示，准备回收
```

### 流程 4: update() 方法（渲染循环）

```
update()
│
├── 1. requestAnimationFrame 递归调用
│   └── this.timer = window.requestAnimationFrame(async () => { ... })
│
├── 2. 回收过期弹幕
│   └── this.filter('emit', (danmu) => {
│         const emitTime = (Date.now() - danmu.$lastStartTime) / 1000
│         danmu.$restTime -= emitTime
│         danmu.$lastStartTime = Date.now()
│         if (danmu.$restTime <= 0) {
│           this.makeWait(danmu)  // 回收到 wait 状态
│         }
│       })
│
├── 3. 获取待显示弹幕
│   └── const readys = this.readys
│       └── 从 states.wait 中筛选时间匹配的弹幕
│           └── currentTime + 0.1 >= danmu.time >= currentTime - 0.1
│
├── 4. 遍历每条待显示弹幕
│   └── for (let i = 0; i < readys.length; i++) {
│         const danmu = readys[i]
│
│         // 防止重复处理
│         if (danmu.$state === 'emit') continue
│
│         // 调用 beforeVisible 过滤器
│         const state = await this.option.beforeVisible(danmu)
│
│         if (state) {
│           // 4.1 获取 DOM 节点
│           danmu.$ref = this.$ref  // 从池中取或创建
│           danmu.$ref.textContent = danmu.text
│
│           // 4.2 添加合并标记
│           if (danmu._mergeCount && danmu._mergeCount > 1) {
│             const mark = document.createElement('span')
│             mark.className = 'art-danmuku-merge-mark'
│             mark.textContent = ` ∑ ${danmu._mergeCount}`
│             danmu.$ref.appendChild(mark)
│           }
│
│           // 4.3 添加到 DOM
│           this.$danmuku.appendChild(danmu.$ref)
│
│           // 4.4 设置样式
│           danmu.$ref.style.opacity = this.option.opacity
│           danmu.$ref.style.color = danmu.color
│           danmu.$ref.style.border = danmu.border ? `1px solid ${danmu.color}` : null
│           danmu.$ref.style.backgroundColor = danmu.border ? 'rgb(0 0 0 / 50%)' : null
│
│           // 4.5 英雄弹幕放大字号
│           if (danmu._isHero) {
│             const rate = Math.min(Math.log(danmu._mergeCount) / Math.log(5), 3)
│             danmu.$ref.style.fontSize = `${Math.ceil(this.fontSize * rate)}px`
│             danmu.$ref.style.textShadow = '2px 2px 4px rgba(0,0,0,0.8)'
│           } else {
│             danmu.$ref.style.fontSize = `${this.fontSize}px`
│           }
│
│           // 4.6 计算剩余时间
│           const distance = clientWidth + danmu.$ref.clientWidth
│           danmu.$restTime = distance / this.velocity
│           if (danmu.mode === 1) {
│             danmu.$restTime = danmu.$restTime / 2  // 顶部弹幕时间减半
│           }
│
│           // 4.7 速度抖动（±20%）
│           const jitter = Math.random()
│           if (jitter < 0.15) danmu.$restTime *= 0.8
│           else if (jitter > 0.85) danmu.$restTime *= 1.2
│
│           // 4.8 发送给 Worker 计算 top 值
│           const { result: top } = await this.postMessage({
│             type: 'getDanmuTop',
│             target: {
│               mode: danmu.mode,
│               height: danmu.$ref.clientHeight,
│               width: danmu.$ref.clientWidth,
│               isHero: !!danmu._isHero
│             },
│             visibles: this.visibles,
│             antiOverlap: this.option.antiOverlap,
│             gap: this.option.gap,
│             fontSize: this.fontSize,
│             clientWidth, clientHeight,
│             marginBottom: this.marginBottom,
│             marginTop: this.marginTop
│           })
│
│           // 4.9 应用位置和动画
│           if (top !== undefined) {
│             this.setState(danmu, 'emit')
│             danmu.top = top
│             danmu.$ref.style.top = `${top}px`
│             danmu.$ref.style.visibility = 'visible'
│
│             // 根据模式设置动画
│             switch (danmu.mode) {
│               case 0:  // 滚动弹幕
│                 danmu.$ref.style.left = '0px'
│                 danmu.$ref.style.transform = `translateX(${clientWidth}px)`
│                 danmu.$ref.style.transition = 'none'
│                 danmu.$ref.clientWidth  // 强制重排
│                 danmu.$ref.style.transform = `translateX(${-danmu.$ref.clientWidth}px)`
│                 danmu.$ref.style.transition = `transform ${danmu.$restTime}s linear 0s`
│                 break
│               case 1:  // 顶部弹幕
│                 danmu.$ref.style.left = '50%'
│                 danmu.$ref.style.marginLeft = `-${danmu.$ref.clientWidth / 2}px`
│                 break
│             }
│
│             this.art.emit('artplayerPluginDanmuku:visible', danmu)
│           }
│         }
│       }
│
└── 5. 递归调用
    └── if (!this.isStop) this.update()
```

## 模块 3: worker.js（Web Worker 轨道计算 + WASM 合并）

**文件路径**: `src/worker.js`  
**代码行数**: 303 行  
**职责**: 在 Web Worker 中处理弹幕轨道计算和单 Worker WASM 合并

### 架构说明

worker.js 同时处理两种任务：
1. **轨道计算** (getDanmuTop)：轻量级，每次渲染循环调用
2. **弹幕合并** (mergeDanmuku)：重量级，WASM 相似度检测

对于多 Worker 并行合并，使用独立的 `merge-worker.js`。

### 流程 1: 顶部弹幕 (mode=1)

```
顶部弹幕轨道分配
│
├── 1. 计算轨道参数
│   ├── trackHeight = fontSize × 1.125
│   ├── maxTop = clientHeight - marginBottom
│   └── totalTracks = (maxTop - marginTop) / trackHeight
│
├── 2. 检查数量限制（英雄除外）
│   ├── normalCount = 非英雄顶部弹幕数量
│   └── if (!isHero && normalCount >= totalTracks/2) → 返回 undefined
│
├── 3. 收集已占用区域
│   └── occupied = 所有 mode=1 弹幕的 { top, bottom } 列表
│
├── 4. 查找可用位置
│   └── for (tryTop = marginTop; tryTop + height <= maxTop; tryTop += trackHeight) {
│         tryBottom = tryTop + height
│         if (!occupied.some(r => tryTop < r.bottom && tryBottom > r.top)) {
│           available.push(tryTop)
│         }
│       }
│
├── 5. 随机选择
│   └── return available[Math.floor(Math.random() * available.length)]
│
└── 6. 无可用位置 → 返回 undefined
```

### 流程 2: 滚动弹幕 (mode=0)

```
滚动弹幕轨道分配
│
├── 1. 收集已占用轨道
│   └── occupiedTracks = Map<top, rightEdge>
│       └── 遍历所有 mode=0 弹幕，记录每条轨道的最右边缘
│
├── 2. 生成所有可能的轨道位置
│   └── allTrackPositions = [marginTop, marginTop+trackHeight, ...]
│
├── 3. 查找可用轨道
│   └── for (trackTop of allTrackPositions) {
│         if (!occupiedTracks.has(trackTop)) {
│           // 空轨道，直接可用
│           availableTracks.push(trackTop)
│         } else {
│           // 有弹幕，检查右侧是否有足够空间
│           lastRight = occupiedTracks.get(trackTop)
│           minHorizontalGap = max(20, clientWidth × gap/100)
│           if (lastRight + minHorizontalGap <= clientWidth) {
│             availableTracks.push(trackTop)
│           }
│         }
│       }
│
├── 4. 随机选择
│   └── if (availableTracks.length > 0) {
│         return availableTracks[Math.floor(Math.random() * availableTracks.length)]
│       }
│
├── 5. 防重叠：在已有轨道之间寻找空隙
│   └── if (antiOverlap && rolling.length > 0) {
│         // 按 top 排序所有轨道
│         // 在轨道之间查找空隙
│         // 如果空隙 >= target.height + 18px，则可用
│         return availableGaps[Math.floor(Math.random() * availableGaps.length)]
│       }
│
└── 6. 无可用轨道 → 返回 undefined
```

**职责**: 并行 WASM 合并，每个 Worker 实例独立加载 WASM，处理时间分片

### 架构说明

当弹幕数量 >= 5000 时，系统会创建多个 merge-worker 实例并行处理：
- 每个 Worker 独立加载 WASM 实例（~5MB 内存）
- 按时间区间将弹幕分成 N 个分片（N = CPU 核心数 - 1，最多 8 个）
- 各 Worker 并行执行预处理 + WASM 相似度检测
- 主线程收集所有结果后合并排序

### 核心函数

```javascript
// WASM 初始化
async function initWasm(wasmUrl)
function beginChunk(maxDist, maxCosine, trimPinyin, crossMode)
function detectSimilarity(str, mode, indexL)

// 预处理（内联，避免 import 问题）
function preprocess(text)

// 弹幕合并
function mergeDanmuku(danmuku, options)
function processChunk(chunkItems, opts)
```

### 消息协议

```javascript
// 初始化 WASM
{ type: 'init', wasmUrl: string, id: number }
→ { ready: true, id: number } | { error: string, id: number }

// 处理分片
{ type: 'process', items: Array, options: Object, id: number }
→ { result: Array, id: number } | { error: string, id: number }
```

### 并行 Worker 数量决策

```javascript
function getWorkerCount(danmukuCount) {
  if (danmukuCount < 5000) return 1           // 少量弹幕，单 Worker
  const hw = navigator.hardwareConcurrency || 4
  return Math.min(hw - 1, 8)                  // 最多 8 个，至少留 1 核给主线程
}
```

| 骁龙870 | 8核 | 7 | ~200ms |
| 老设备 | 4核 | 3 | ~500ms |

### 流程

```

│
```

```
│   └── for (const d of danmus) { d._isHero = false }
│

│         hero.mode = 1  // 顶部模式
│
│         // 3.6 同桶其余 ∑ > 5 降级
│         for (const d of bucket) {
│           if (d !== hero && d._mergeCount > 5) {
│             d.mode = 0  // 强制滚动模式
│           }
│         }
│       }
```

### XML 格式

### 解析规则

```javascript
function bilibiliDanmuParseFromXml(xmlString) {
  const reg = /<d[^>]*?p="(?<p>[^"]+)"[^>]*>(?<text>.*?)<\/d>/gs

  return Array.from(xmlString.matchAll(reg))
    .map(match => {
      const attr = match.groups.p.split(',')
      return {
        text: match.groups.text,           // 弹幕文本
        time: Number(attr[0]),            // 时间（秒）
        mode: getMode(Number(attr[1])),   // 模式
        fontSize: Number(attr[2]),        // 字号
        color: `#${Number(attr[3]).toString(16)}`,  // 颜色
        timestamp: Number(attr[4]),       // 时间戳
        pool: Number(attr[5]),            // 池
        userID: attr[6],                  // 用户ID
        rowID: Number(attr[7]),           // 行ID
      }
    })
}

function getMode(key) {
  // 1-4: 滚动, 5: 顶部
  return (key === 5) ? 1 : 0
}
```

### v5.3.0 - 修复倍速切换后飞行中弹幕不回速

**日期**: 2026-09-01

**变更内容**:

1. **修复 synchronousPlayback 倍速同步只在弹幕出现时生效一次的问题**
   - 之前：`$restTime` 与 CSS transition 在弹幕出现时按当时倍速一次性算死（spawn 时 `distance / this.velocity`），插件未监听 ratechange；飞行中的弹幕在倍速变化后永远保持出现时的速度——按住右箭头 2x 松开后，已 2x 的弹幕不回原速提前飞完；反向 1x 在飞弹幕也不会加速
   - 之后：新增 `rateChange()` 方法并监听 `video:ratechange`，倍速变化时按新旧倍速比换算所有 emit/stop 弹幕的剩余时长（`t_new = t_old × r_old / r_new`，等价于按新倍速重新 spawn，保留速度抖动与顶部弹幕减半语义），滚动弹幕（mode 0）冻结当前位置后按新速度无缝续播；暂停中的弹幕只换算剩余时长，恢复时由 `continue()` 按新速度续播
   - `_playbackRate` 记录上次倍速；synchronousPlayback 关闭时只记录不缩放，重新开启后的下一次 ratechange 自动恢复一致

2. **文件变更**
   - 修改: `src/danmuku.js` — 构造函数初始化 `_playbackRate` 并绑定 `video:ratechange`，新增 `rateChange()` 方法，`destroy()` 注销监听
